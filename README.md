# 小宝贝成长记

一个只属于我们家的宝宝成长小站 —— 从备孕、孕程，到出生、长大，一路记录到 18 岁以后。

**技术**：Vite + React + TypeScript，纯前端、无后端，数据保存在浏览器 localStorage 里，离线也能用。

---

## 快速开始

```bash
npm install      # 安装依赖
npm run dev      # 本地开发，浏览器打开 http://localhost:5173
npm run build    # 打包到 dist/
npm run preview  # 本地预览打包结果 http://localhost:4173
```

## 怎么用

### 首页
- 自动显示：当前孕周 / 宝宝年龄、一起走过的天数、预产期。
- 数据都来自「设置」里填的日期，填好一次就自动算。

### 时间轴
- 从「一颗种子的愿望」到「18 岁以后」，共 13 站，左右交替排开。
- 每一站有一段**写给宝宝的温柔对话**和一组**里程碑**，做过了就打个勾，会自动记住。
- 当前所在的一站会呼吸发光。

### 时光胶囊
- 写一封「悄悄话」，选好宝宝多少岁打开（1/3/6/12/18 岁，或自定义日期），到时间才能拆开。
- 预置了 3 岁、12 岁、18 岁三封示例信，可以删掉重写。

### 成长的每一页
- 照片 + 标题 + 一句话，记下舍不得忘记的瞬间。照片会自动压缩后再保存，不占空间。

### 设置
- **末次月经日期**：填了它，孕周和预产期（LMP + 280 天）都会自动推算。宝宝出生后填上出生日期，就自动切换到按年龄计算。
- 宝宝名字 / 称呼、3 套主题色。
- **导出备份 / 导入备份**：建议每次记完重要内容就导出一次 JSON 存好。

## 数据与备份

- 所有记录都存在**这台设备浏览器的 localStorage** 里，清除浏览器数据会丢失。
- 换手机、换电脑前，请先在「设置」里**导出备份**，新设备上**导入备份**即可全部找回。
- 备份文件是一个 JSON，可以自己保存到网盘、U 盘。

## 部署到网上（可选）

项目是纯静态站点，任何静态托管都可以直接部署：

- **Vercel**：导入仓库，Framework Preset 选 Vite，Build Command `npm run build`，Output Directory `dist`。
- **Netlify**：Build command `npm run build`，Publish directory `dist`。
- **GitHub Pages**：把 `dist/` 内容推到 `gh-pages` 分支（需要把 `vite.config.ts` 里的 `base` 改成仓库名路径）。

> 部署后每个家人的浏览器都是独立的数据，备份 / 导入是唯一的同步方式。

## 项目结构

```
src/
  data/stages.ts        # 13 个成长阶段的内容 + 温柔对话
  lib/dates.ts          # 孕周 / 年龄 / 预产期推算
  lib/storage.ts        # localStorage 读写、默认数据、导出 / 导入
  lib/types.ts          # 数据类型
  components/           # 页面各部分组件
  styles/               # 样式（tokens / base / sections）
```
